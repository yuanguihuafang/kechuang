## DeerFlow 运行目录与版本控制

- DeerFlow 运行数据位置以进程实际 `DEER_FLOW_HOME` 和容器挂载为准，不假定为源码目录下 `.deer-flow`。SQLite、`users/`、Agent、检索数据和密钥均不是缓存清理目标；不要整目录删除。停止 Gateway 后才可按需处理已确认的锁文件。
- OPIEos 当前源码目录为 `OPIEos/`；Agent 源资产位于其 `agents/kechuang/`。共享 Skill 源目录按 Agent 配置和实际运行时 `skills.path` 核验，部署前确认挂载路径；不要把历史 `skills/custom` 布局直接当作当前事实。运行配置中的 `extensions_config.json` 不放真实凭据进归档。
