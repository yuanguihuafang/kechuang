## 2026-10-15 检索库范围由模型按意图选择

- 字段提取缓存按实际送入模型的文本段计算；原文为空而使用解析块时，不同材料不得复用缓存。
- 检索全部不可用（`DEGRADED`）在 Agent 外层返回 `FAILED`，保留业务负载与错误；`PARTIAL_SUCCESS` 保持部分成功。换批仅对正常检索的空结果返回“没有更多匹配结果”，故障不得转换为空结果。

- 用户明确或语义明确限定资料类型时，由模型判断并只检索对应库，不按关键词硬编码；未限定时沿用业务流程原有范围。需求找供给并行检索方案、成果、专家、企业，供给找需求只检索需求库；不默认扩成全部知识库。
- 实际检索范围随结果写入会话状态，换一批严格沿用并排除已展示结果；即使无新结果也不自动扩大范围。
- 首次同一来源同时命中原文和草稿时仍优先展示原文，并关联最高分草稿。换批按知识类型及文档 ID 排除已展示文档的所有原文块（包括其他 source_id 的引用），按知识类型及 MySQL ID 排除已展示草稿；首次原文关联的选中草稿也记为已展示。同一 source_id 下其他草稿仍可参与下一批。排除在重排前完成，详情查询不受换批排除条件限制。
- 换一批没有新结果时返回“当前知识库没有更多匹配结果”；联网回退沿用首轮 Agent 对完整目标和来源限制的判断，不因换批扩大知识库范围。

## 目标与边界

- PPT/PPTX 固定由本地 MinerU CLI 解析，不走 HTTP MinerU 或 PaddleOCR；PDF、图片及其他格式保持原有路由。本地解析器不可用时直接报错，不回退远端。

- 知识库/供需匹配摘要由模型按提示总结在 200 字以内；不得用字符截断代替总结，完整信息由结构化卡片承载。
- “换一批”复用会话内原始查询、方向和已展示对象；服务端排除旧对象。无新结果时明确告知，不让模型从历史对话重复上一批。
- 供需匹配没有可检索主题时只澄清一个关键点，不调用检索工具；可检索主题和方向足够后立即匹配。预算、数量等剩余信息是可选补充，不能阻止匹配。
- 企业画像与需求发现使用匹配卡片呈现完整、可追溯资料，正文只保留简短概述。没有相关客户拜访证据时不输出无关拜访记录。
- 文档解析保留当前文件解析、草稿生成、SSE 和公开 API 语义；消除人为流式限速，补齐真实处理时间边界。对 MinIO 传输和 LLM 并发仅在计时证据充分后再优化。
- 不改变前端 API 参数/事件合同，不修改 OPIEos/DeerFlow 核心，不删除旧 Supervisor 或其回退路径。

## 当前调用链发现

- DeerFlow 适配层及旧 Reasoning Agent 都存在 200 字后处理硬截断；模型提示已有长度要求，应移除截断并保留提示式总结。
- 固定快速入口在 DeerFlow 适配层先计算了旧流程澄清响应，却仍启动 `runner.stream()`；无主题的入口因此可能继续触发 MCP 检索。
- 已展示批次保存在会话状态，但没有结果时模型仍可从对话历史复述上一批；空批次应由后端确定性反馈。
- 企业画像已映射为推荐卡片，但 MySQL 画像缺少可用详情定位，公开结果又移除 `details`，使卡片不如正文完整。需求发现未把 `kc_customer` 的相关访问信息映射为结果卡片，且工具目前可返回该用户所有有效拜访记录。
- 材料 SSE 将输出切为每 5 个字符并固定等待 100ms；队列排空时间不在 `processing_elapsed_ms` 中。解析后的多段需求抽取按段串行调用 LLM；其额外并发/上传下载优化须先用阶段数据评估。

## 实施与验收

1. 摘要：Adapter/旧推理路径保留模型生成的完整总结，不按字符截断；提示明确要求不超过 200 字。测试验证超过 200 字的模拟模型结果未被静默截去尾部。
2. 换批：保存 query、方向和已展示 ID；模型漏回 query/direction 时从本轮请求/草稿状态补齐。Gateway 把排除 ID 作为内部字段传给适配层，MCP 检索与卡片合并都排除旧对象；无新结果时正文和卡片都不复述上一批。
3. 意图：固定“供需匹配”入口只返回原流程方向/主题澄清 UI，不启动 DeerFlow run；只有主题足以检索后才调用匹配。用户无需先建立草稿或填写所有可选项。
4. 卡片：画像与需求发现结果详情进入公开的结构化卡片合同，摘要正文精简；需求发现仅返回与查询相关的画像/拜访证据，不展示空命中或无关拜访内容。
5. 解析：移除每个 SSE 小片段的固定 sleep，保留事件顺序及内容；最终耗时覆盖事件队列排空。保持上传、解析和摘要串行依赖，暂不推测式引入并发。
6. 回归：定向后端测试、全量后端测试和前端构建；保持外部接口参数、原快速入口业务步骤和回退路径不变。
