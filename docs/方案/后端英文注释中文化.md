# 后端英文注释中文化

## 范围

- 仅处理 `backend/` 下 Python 文件中的英文说明注释和英文分区标题，包含测试与迁移脚本。
- 只改注释文字，不改代码逻辑、字符串、标识符、日志、API 文案或配置值。
- 保留 `type: ignore`、`noqa`、`pragma` 等工具指令，以及 MCP、Milvus、LLM 等技术名；工具指令后的英文说明翻译成中文。
- 已有中文注释中的英文技术名不做改写。

## 验证

- 修改前后比较 Python Tokenizer 识别的注释 token，确认差异只落在注释内容。
- 对修改涉及的 Python 文件执行语法编译检查；不运行会连接真实数据库、模型或外部服务的测试。
