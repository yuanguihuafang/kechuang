# 管理台字段权限外部隐藏字段展示

## 目标

字段访问规则页仅对需求库、企业库分别展示公开字段和外部用户脱敏字段；其他知识库继续将业务字段合并展示，避免把一般内部字段误标为外部脱敏。系统字段始终单独展示。

## 范围

- 仅调整管理台字段权限页面的分组和样式。
- 仅 `enterprise`、`demand` 将 `public` 与 `internal` 分开，并将 `internal` 标注为“外部用户脱敏字段”；其他类型合并为业务字段。
- 需求库 `first_img_url`（需求封面）属于公开字段；仅 `link_name`、`link_tel` 为外部隐藏字段，`pub_dept`、`company` 对外可见。企业库仅 `created_by`、`business_scope` 为外部隐藏字段，其余业务字段公开。
- 字段顺序沿用后端接口，不改变实际访问权限或 API。

## 验收

- 需求库、企业库的 `public` 与 `internal` 字段分别显示，不合并、不丢失、不重复。
- 其他知识库不显示“外部用户脱敏字段”分组，原业务字段保持合并展示。
- `system` 字段继续单独显示。
- 无配置知识库仍显示原有未配置说明。
