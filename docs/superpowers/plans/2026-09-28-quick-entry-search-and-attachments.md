# 快速入口、检索与附件修订计划

1. 回归测试覆盖普通消息请求契约、首轮宽泛业务请求交给 Agent、手动供需方向优先级、需求发现不建草稿、换批排除/语义触发和联网输出规则。
2. 首页三个问题与自由输入一样提交普通消息，不增加专用标记或固定答复分支；在科创 Agent 系统提示词中约束所有信息不足的首轮业务请求先用中文自然追问、不检索、不建草稿，并把三个入口话术作为可改写的参考示例。
3. 将排除 ID 送入实际检索工具，扩大候选召回并在重排/业务去重后筛除旧结果，最终截取前三条；由 Agent 对本次工具调用设置语义换批标志；不持久化换批临时状态；保存并复用用户确认的方向。
4. 更新科创 Agent 的需求发现/联网 Skill：需求发现主题足够即检索，不建草稿；联网答案按条列出、不显示 URL，不套用内部知识库 200 字规则。
5. 附件子任务独立核对草稿工具保存、附件存储 API、用户草稿详情和管理台读取；修复关联及最小展示/下载/删除缺口。
6. 运行定向测试、前端测试/构建与差异检查；不启动服务，明确在线验证边界。
