# About OPIE OS

**OPIE OS** is an AI agent platform self-developed by the OPIE team. With sandboxes, memories, tools, and skills, it handles different levels of tasks that could take minutes to hours.

---

## 🚀 Core Features

* **Skills & Tools**: Built-in and extensible skills let OPIE OS handle a wide range of tasks.
* **Sub-Agents**: Sub-agents break complex work into parallel, focused threads.
* **Sandbox & File System**: Safely execute code and manipulate files in an isolated sandbox.
* **Context Engineering**: Isolated sub-agent context and summarization keep the context window sharp.
* **Long-Term Memory**: Continuously capture user profile, top-of-mind, and conversation history.
